## 二、给代码 AI 的结构化提示词（可直接粘贴）

```
用 Three.js 建一朵参数化玫瑰，单文件 HTML。
花瓣 = NU×NV 的曲面网格，沿长度做弧线翻卷：y=L·u·cos(fold·u^1.35)，z=L·u·sin(fold·u^1.35)，
宽度 profile 用 0.54+0.46·sin(π·u^0.74)^0.46，横向 cup 让内外层分别凹/凸。
每片花瓣绕 Y 轴按黄金角 2.39996 螺旋排布，半径 = (0.09+0.44·t^0.95)·open。
生命周期用一个 life∈[0,1] 驱动：open=clamp((life-0.05)/0.42)，wither=clamp((life-0.68)/0.32)，
同时驱动长度、宽度、fold、cup、颜色（root→mid→tip 渐变，衰败向 dry 褐化）、
花瓣脱落（每片随机 dropAt，落下时 y 下坠、外飘、旋转、缩小）、花头倾角与茎的弯曲。
光照：暖白主光带 PCF 软阴影 + 青绿轮廓光 + 环境光；材质 MeshPhysicalMaterial，roughness .52，clearcoat .18，顶点色。
```

## 三、负向约束（避免 “塑料感” 和 “AI 插画感”）

```
不要平面插画感、不要纯色块贴图、不要塑料反光、不要过度唯美柔焦、
不要对称完美的几何花瓣、不要卡通描边、不要平涂渐变、不要紫色调背景
```
流程已经执行完成：先生成了六张同一机位、同一光线的状态参考图，再拿它们对照着改了代码。

以下参数是按参考图校准过的：

- 配色改为深酒红 `#2B0409 → #8C0E1F → #CE2A3C`，基本去掉了原来的粉白偏移
- 把光比拉到参考图的水平：环境光压到 0.26、主光提到 2.5、曝光 0.9

- 花冠改为内层矮瓣收进、外层大瓣外翻，花心补了一个卷心球
- 萼片按图加长到 0.70 并收窄成尖瓣
- 落瓣规律改成外层先落、内层残瓣不倒，边落边向外飘，不再直落
