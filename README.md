## 一、客观外形描述（科普、介绍用）

玫瑰是蔷薇科蔷薇属落叶灌木，花形端庄，花瓣层层叠叠、由外向内渐进收拢，质感厚实带丝绒感。颜色以红、粉、白、黄为主，另有香槟、紫、渐变等园艺品种。茎干挺直，多带皮刺；叶片奇数羽状，表面有细小皱纹与锯齿。香气浓郁而清甜，是最早在文字中被记录的 “香花” 之一。花期为春末至初夏，一年可多次开花。

## 二、花语与寓意（按颜色）

表格

| 颜色 | 常见含义 |
| --- | --- |
| 红玫瑰 | 热烈的爱与真挚的感情 |
| 白玫瑰 | 纯洁、尊重、纯洁的爱 |
| 粉玫瑰 | 初恋、温柔的关怀、感动 |
| 黄玫瑰 | 友谊、祝福（也有歉意、失恋说法，看语境） |
| 香槟、蜜桃 | 优雅、珍贵、只属于你 |
| 紫玫瑰 | 浪漫、珍贵独特 |

朵数也有讲究：1 朵 “唯一”，11 朵 “一心一意”，33 朵 “三生三世”，99 朵 “天长地久”，108 朵常用作求婚。

## 三、文学化描写（写文案、作文可直接改）

- 它开得不张扬，却让人移不开眼 —— 花瓣一层压着一层，红得像把光收进了心里。
- 玫瑰的美带着棱角：香气温柔，茎上全是刺，像所有不肯轻易低头的爱。
- 清晨的玫瑰最好看，露水还挂在花瓣边缘，像刚刚忍住的眼泪。
- 花语说的是爱，但玫瑰本身更像一种态度：热烈、明确、有边界。
## 四、做成了一个单文件页面：用 Canvas 里的代码程序化 “长” 出玫瑰，不依赖任何图片素材。

**核心算法**（源码都在这个 HTML 里，可直接改）：花瓣按黄金角 137.5° 由内向外螺旋排布，每片的半径、宽度、卷曲、缺口和投影都由参数算出，外层大瓣压住内层小瓣，形成层层包裹。

**五个参数即可描述一种状态**：

- 品种：红、白、粉、香槟，每套有自己的明暗色阶
- 开度：2%–100%，从小而紧凑到完全舒展，花头尺寸与花瓣宽度同步变化
- 花瓣数：20–52
- 卷曲度：花瓣尖端的偏移程度
- 随机种子：同一组参数可以复现同一朵花

右侧可实时看到参数 JSON 并一键复制，另外支持导出 1600×1600 PNG，配色会随背景一起导出。

说明一句：这是程序化渲染的花，质感偏插画式（花瓣边缘带硬边），不是照片级写实；
